# ADR-0020. Сжимать статику на сборке панели, а не в демоне

- Статус: Accepted
- Дата: 2026-09-16
- Ответственные: владелец репозитория

## Контекст и постановка проблемы

Демон раздавал встроенную SPA как есть: `http.FileServerFS` без сжатия. Первый заход на панель — 1193 КБ на 31 файл, из них 1099 КБ JavaScript. Данные измерены на собранном бинаре `curl`'ом.

Вопрос встал вместе с локализацией ([ADR-0019](./ADR-0019-keep-interface-texts-in-the-slice-and-load-them-over-the-network.md)): словарей стало пятьдесят, они мелкие, и раздача без сжатия и без вечного кэша означала бы перезапрос текста на каждом заходе.

Ограничения, заданные раньше:

- `go.mod` демона держится без `require` — новая зависимость требует отдельного решения ([Architecture&Style демона](../../apps/metaboxd/docs/guides/Architecture%26Style.md));
- статика лежит внутри бинаря, который ставится на роутер пакетом apk ([ADR-0011](./ADR-0011-ship-the-daemon-as-an-apk-package.md)), поэтому размер бинаря — это место во флеше устройства;
- NFR-4 ограничивает демон: RSS ≤ 64 МБ, CPU в простое ≤ 1% одного ядра;
- панель раздаётся по обычному http в локальной сети, TLS у неё нет.

В scope — как сжатая статика доезжает до браузера. Вне scope — сжатие ответов API: они мелкие и ходят по одному.

## Критерии выбора

- Процессорное время роутера на запрос не растёт: устройство слабее любого клиента, который к нему ходит.
- Новых зависимостей у демона не появляется.
- Работает по обычному http, без TLS.
- Клиент, который сжатого не принимает, получает исходный файл.
- Место во флеше тратится осознанно и измеримо.

## Рассмотренные варианты

1. **Предсжатие на сборке панели, выбор варианта в демоне** — сборка кладёт рядом с файлом `.br` и `.gz`, демон выбирает по `Accept-Encoding` и ставит `Vary`. Плюсы: на запрос демон тратит столько же, сколько раньше, — читает файл и отдаёт; brotli максимального качества считается один раз на сборке, где времени не жалко; зависимостей ни у демона (варианты только читаются), ни у панели (brotli есть в Node) не появляется. Минусы: в бинаре лежат вторые копии файлов. **Принят.**

2. **Сжатие на лету в демоне** — `compress/gzip` из стандартной библиотеки, middleware поверх раздачи. Плюсы: бинарь не растёт, `.br` не нужен. Минусы: один и тот же файл жмётся на каждый запрос, и тем чаще, чем слабее железо; brotli в стандартной библиотеке нет, то есть лучший формат так не получить вовсе. **Отклонён.**

3. **Сжатие на лету с кэшем сжатого в памяти** — жать один раз и держать результат. Плюсы: бинарь не растёт, процессор тратится однократно. Минусы: сжатая статика переезжает в RSS, который ограничен NFR-4, и держится там всё время работы демона ради данных, известных ещё на сборке. **Отклонён.**

4. **Включить HTTP/2** вместо сжатия или вместе с ним. Плюсы: мультиплексирование, нет лимита в шесть соединений на origin. Минусы: в браузере HTTP/2 работает только поверх TLS — открытого текста (h2c, `Protocols.SetUnencryptedHTTP2` в стандартной библиотеке Go) не поддерживает ни один браузер. TLS на роутере означает самоподписанный сертификат и предупреждение при каждом заходе. В локальной сети с RTT меньше миллисекунды выигрыш от мультиплексирования близок к нулю, а трафик он не сокращает вовсе. **Отклонён** — до тех пор, пока у панели не появится TLS по другой причине.

5. **Сохранить текущий подход** — раздавать как есть. Минусы: 1193 КБ на первый заход по локальной сети и полсотни перезапрашиваемых словарей. **Отклонён.**

## Принятое решение

Сжимает сборка панели. Плагин `metabox-compress` кладёт рядом с каждым сжимаемым файлом `dist` два варианта: `.br` (brotli, максимальное качество) и `.gz` (gzip -9). Жмутся `.js`, `.css`, `.html`, `.json`, `.svg`; файл меньше 256 байт и вариант, который выиграл меньше десятой части, не пишутся. `woff2` не жмётся — он уже сжат.

Оба формата, а не только brotli: панель живёт по обычному http, и браузер объявляет `br` не на всяком соединении.

Демон выбирает вариант по `Accept-Encoding`, ставит `Content-Encoding` и `Vary: Accept-Encoding`. Правила раздачи:

- тип содержимого берётся у исходного имени: по расширению `.br` он определился бы как поток байт;
- токен с нулевым весом (`br;q=0`) считается отказом, а не выбором;
- варианта нет или клиент его не принимает — уходит исходный файл;
- сам `.br` или `.gz` адресом не является: прямой запрос получает оболочку, иначе клиент увидел бы нераспакованные байты.

Вечный кэш остаётся привязанным к отпечатку в имени — правило не меняется, под него теперь попадают и словари локализации.

### Область действия и границы

`apps/web/vite.config.ts` (плагин `metabox-compress`) и `apps/metaboxd/internal/webui`. API демона, поток рантайма и прокси Clash API не затронуты.

## Последствия

### Положительные

- Первый заход — 298 КБ вместо 1193 КБ, на 75% меньше по сети. Главный чанк: 307 КБ → 84 КБ (brotli) или 96 КБ (gzip).
- Процессорное время демона на запрос не изменилось: он отдаёт файл, просто меньший.
- Словари локализации попали под вечный кэш вместе с остальными ассетами.

### Отрицательные

- Каталог статики вырос с 1.6 до 2.0 МБ, и на столько же — бинарь: в нём лежат вторые копии файлов.
- Сборка панели идёт 4.9 с вместо ~1 с: brotli максимального качества считает медленно.
- Раздача перестала быть одним вызовом `http.FileServerFS`: появился разбор `Accept-Encoding` и своя запись ответа. Это проверяется тестами, но это код, которого не было.
- `Range` на сжатом ответе адресует сжатые байты. Так же ведёт себя `gzip_static` в nginx; для статики панели сценария нет.

### Нейтральные или отложенные

- HTTP/2 не включается, пока у панели нет TLS. Появится TLS — Go поднимет h2 по ALPN сам, отдельного решения это не потребует.
- Сжатие ответов API не вводится: они мелкие и ходят по одному.

## Совместимость, миграция и откат

Миграции нет: варианты появляются в `dist` при следующей сборке, а клиент, который их не принимает, получает то же, что и раньше. Старые клиенты не затронуты — согласование идёт по заголовку, который браузеры шлют всегда.

Откат — убрать плагин из сборки: демон, не найдя вариантов, вернётся к раздаче исходных файлов без правок в нём самом.

## Проверка решения

- `cd apps/metaboxd && go test ./internal/webui/` — выбор варианта по `Accept-Encoding`, включая `br;q=0`; тип содержимого от исходного имени; вечный кэш на словаре с отпечатком; `.br` как адрес не отдаётся;
- `make daemon` и `curl -H 'Accept-Encoding: br'` по собранному бинарю — заголовки `Content-Encoding`, `Content-Type`, `Vary`, `Cache-Control` и размер ответа;
- сравнение размеров первого захода с `Accept-Encoding: identity` и `br` на одном и том же наборе файлов.
