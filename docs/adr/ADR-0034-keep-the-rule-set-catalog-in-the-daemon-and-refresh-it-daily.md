# ADR-0034. Держать каталог наборов в демоне и сверять его с поставщиками раз в сутки

- Статус: Proposed
- Дата: 2026-09-25
- Ответственные: владелец репозитория

## Контекст и постановка проблемы

AC-7 требует каталог готовых наборов с выбором поставщика и поиском по категориям, который открывается без доступа к сети. До этого решения перечень категорий был снимком, собранным при сборке панели и лежавшим в её бандле. Снимок расходится с тем, что поставщики публикуют: Runet Freedom и v2fly добавляют и убирают категории, а панель узнавала об этом только с новой сборкой. Категория, которой у поставщика уже нет, собирает адрес на несуществующий файл, и sing-box с таким набором не стартует.

Ограничения, заданные раньше:

- Демон до этого решения не ходил в интернет: его HTTP-запросы шли только к локальному Clash API.
- Правило [DeviceIO](../../apps/metaboxd/docs/guides/DeviceIO.md): фоновых опросов по таймеру без потребителя нет, исключение заводится только с разбором цены.
- У роутера нет часов реального времени ([ADR-0002](./ADR-0002-apply-protocol-and-config-ownership.md)): после включения он стартует с эпохи.
- Служебным каталогом демона владеет `config.Store` — один владелец на ресурс.

Факты о внешнем источнике, замеренные 2026-09-25:

- Перечень файлов поставщика отдаёт GitHub REST API (`git/trees`): от 67 до 578 КБ на список, около 75 КБ со сжатием.
- Без токена лимит — 60 запросов в час на адрес, и условный запрос по ETag в него тоже засчитывается, хотя ответ `304` приходит без тела.
- jsDelivr как запасной источник перечня не годится: для Runet Freedom он отвечает `403`, пакет больше 50 МБ.
- С BPI-R4 Pro `api.github.com` отвечает за 0,6 с.

В scope — кто хранит каталог, как и когда он сверяется с поставщиками, что видит панель без сети. Вне scope — свои списки пользователя ([ADR-0033](./ADR-0033-keep-custom-rule-lists-in-the-singbox-config.md)).

## Критерии выбора

- Перечень совпадает с тем, что поставщик публикует, с отставанием не больше суток.
- Каталог открывается без интернета (AC-7).
- Один дом для таблицы поставщиков: адреса и шаблоны не дублируются между Go и TypeScript.
- Нагрузка на роутер и на лимит GitHub соизмерима с пользой.
- Новая зависимость в демоне не появляется.

## Рассмотренные варианты

1. **Оставить снимок в бандле панели.** Простейший путь: сеть не нужна вовсе. Но перечень свежий ровно настолько, насколько свежа сборка, и расхождение с поставщиком — штатное состояние. **Отклонён** по первому критерию.
2. **Браузер сам сверяется с GitHub.** Демон не меняется, кэш держит TanStack Query. Кэш живёт во вкладке, и каждый заход тратит по четыре запроса лимита. Браузер без интернета видит только встроенный снимок, а таблица поставщиков остаётся во фронте. **Отклонён.**
3. **Демон сверяется лениво, по запросу панели.** Кэш старше суток отдаётся сразу и обновляется в фоне. Укладывается в правило DeviceIO без исключения. Но первый заход после простоя видит устаревший перечень. **Отклонён** владельцем: перечень должен быть свежим к любому заходу.
4. **Демон владеет каталогом и сверяет его по таймеру.** **Принят.**

## Принятое решение

Каталогом готовых наборов владеет демон, пакет `internal/ruleset`.

- **Таблица поставщиков** живёт только в Go: поставщик, его списки сайтов (`geosite`) и адресов (`geoip`), подборка для пустого поля и каталог ветки на GitHub. Адреса зеркал GitHub и jsDelivr выводятся из каталога ветки, а не записываются отдельно.
- **Снимок** `internal/ruleset/snapshot.json` встраивается в бинарь `go:embed` и собирается командой `make rule-set-snapshot` (`cmd/rulesetsnap`). С ним демон стартует, пока не сверился сам, поэтому каталог открывается и без интернета.
- **Сверка** идёт по таймеру всё время работы демона, открыта панель или нет: сразу, если перечень — снимок или старше интервала, дальше раз в интервал. Интервал задаёт флаг `-rule-set-refresh`: по умолчанию сутки, `0` отключает сверку, интервал короче паузы повтора отвергается на старте. Неудачная сверка повторяется через час, а не через сутки: на старте роутера сеть и часы поднимаются позже демона.
- **Запрос** к `api.github.com/repos/…/git/trees/…` условный, по ETag последней сверки. Ответ `304` оставляет перечень и обновляет дату сверки. Урезанное дерево и дерево без файлов наборов считаются отказом: прежний перечень остаётся.
- **Кэш** сверенного перечня пишет `config.Store` в `<state-dir>/rule-sets.json` атомарной записью с правами 0600. Несверенный снимок в кэш не попадает.
- **Панель** получает каталог ручкой `GET /api/rule-sets/catalog`. Отказ каталога не прячет список наборов: без каталога он виден и правится, а форма остаётся со своим адресом. Схема ответа генерируется `cmd/contractgen`. Панель держит каталог в TanStack Query сутки и своей копии каталога не хранит. У каждого списка в ответе есть источник (`snapshot` или `provider`) и дата, их форма показывает под полем категории.

Non-goals: токен GitHub, разбор `geosite.dat`, проверка существования файла при каждом вводе категории.

### Область действия и границы

`apps/metaboxd/internal/ruleset`, `internal/config` (кэш), `internal/httpapi` (ручка), `cmd/rulesetsnap`, `apps/web/src/entities/RuleSet`, форма `features/RuleSet/RuleSetAdd`.

## Последствия

### Положительные

- Перечень отстаёт от поставщика не больше чем на сутки, и панель это показывает датой.
- Таблица поставщиков записана в одном месте, фронт её не дублирует.
- Каталог открывается без интернета: снимок едет в бинаре демона.

### Отрицательные

- Демон впервые ходит в интернет. Это новая поверхность отказа и третье исключение из правила «фоновых опросов без потребителя нет». Цена — четыре запроса к GitHub раз в сутки и разбор ответов до 600 КБ на время сверки.
- Если GitHub с устройства недоступен, каталог застывает на кэше или снимке, а каждый час в лог падает предупреждение.
- Лимит без токена считается на адрес: за общим NAT его может выбрать кто-то другой, и сверка будет откладываться.
- Снимок нужно пересобирать вручную перед релизом, иначе новая установка стартует со старого перечня.

### Нейтральные или отложенные

- Токен GitHub как флаг — если лимит станет проблемой на практике.
- Настройка интервала через UCI-раздел `metabox` — пока только флагом.

## Риски и меры снижения

| Риск                                                      | Вероятность и влияние                                       | Митигация                                                                                             |
| --------------------------------------------------------- | ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Поставщик сменил раскладку ветки, дерево пустое           | Низкая вероятность, среднее влияние                         | Пустое дерево — отказ, прежний перечень остаётся; тест `TestRefresh`                                  |
| Часы роутера не синхронизованы на старте                  | Высокая вероятность на каждом включении, низкое влияние     | TLS без часов не пройдёт, и сверка повторится через час; перечень с датой из будущего сверяется сразу |
| Подборка ссылается на категорию, которой у поставщика нет | Средняя вероятность, высокое влияние — sing-box не стартует | Тест `TestEmbeddedSnapshot` сверяет подборку с перечнем снимка                                        |

## Совместимость, миграция и откат

Ручка новая, прежние не меняются. Фронтовый снимок `RuleSet.categories.generated.json` и генератор `apps/web/tools/ruleSetCatalog.ts` удалены. Кэш `rule-sets.json` появляется в служебном каталоге после первой сверки, миграции нет. Откат — флаг `-rule-set-refresh 0`: сверки нет, каталог берётся из кэша или встроенного снимка, и демон в сеть не ходит.

## Проверка решения

- `go test -race ./internal/ruleset/... ./internal/config/... ./internal/httpapi/...` — клиент GitHub (200, 304, 403, урезанное дерево), расписание сверки на фиктивных часах, повтор после отказа, ожидание при старте из кэша и с датой из будущего (`TestUntilStale`), отказ от слишком короткого интервала, кэш и ручка.
- `make schema-daemon` печатает `CatalogSchema` в `daemon.generated.ts`.
- Тесты панели: форма собирает адрес по выбранным поставщику и виду списка и показывает дату перечня; таблица наборов называет поставщика и вид списка по каталогу.
- Живой прогон: демон с пустым служебным каталогом стартует со снимка, сверяется за секунды, пишет `rule-sets.json` с правами 0600, ручка отдаёт `source: provider`.
