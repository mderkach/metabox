# Корпус конфигов

Файлы этого каталога — вход golden round-trip: панель обязана разобрать каждый,
сохранить его байты вне правки и не потерять ни одного узла. Проверяет их
`Config.corpus.test.ts`, который подхватывает каталог целиком — новый файл
достаточно положить рядом.

Что здесь должно быть: формы, которые встречаются на живых роутерах, а не
удобные для панели. Комментарии, запятая перед закрывающей скобкой, табы,
CRLF, незнакомые секции, порядок ключей не как в схеме.

Данных владельца здесь быть не может: домены — зоны `.example` и `.invalid`
(RFC 2606), адреса — `198.51.100.0/24` и `203.0.113.0/24` (RFC 5737), ключи и
подписки — `REDACTED`. Файл лежит в git, и дамп с реального устройства сюда не
кладётся.
