## Правки в `apps/metaboxd/`

- Модуль называется `metabox`, поэтому импорты остаются вида `metabox/internal/...` независимо от расположения папки.
- Точка входа — `main.go` в корне модуля: разбор флагов, сборка зависимостей, запуск, ожидание сигнала. Логики в нём нет.
- `cmd/contractgen` — генератор схем контракта для панели: читает исходники `internal/*` и печатает `apps/web/src/shared/api/daemon.generated.ts` ([ADR-0012](../../docs/adr/ADR-0012-generate-daemon-contract-schemas-from-sources.md)). Артефакт коммитится вместе с правкой демона, пересобирается `make schema-daemon`.
- Весь код демона — в `internal/`, режется по предмету, а не по техническому слою.
- Корневой `go.mod` держится без `require`: всё нужное есть в стандартной библиотеке. Новая зависимость — отдельное решение с ADR.
- Сборка, тесты и линт — только через `make` из корня репозитория: теги и флаги форка задаются там.
