# metabox

Веб-панель для sing-box на OpenWrt: графическое редактирование конфига, каталог rule-set и рантайм-дашборд. Поставляется одним Go-демоном со встроенной SPA — на устройство едет единственный бинарь.

Аутентификации в v1 нет — осознанное решение, риск R-1 в PRD. Демон слушает адреса сетей из `listen_interface` в `/etc/config/metabox` — по умолчанию только `lan` ([`apps/metaboxd/package/etc/config/metabox`](./apps/metaboxd/package/etc/config/metabox)) — и не должен быть доступен из интернета: устройство, дотянувшееся до панели, управляет маршрутизацией всей сети.

## Устройство репозитория

Монорепо: каждый проект держит в своей папке код, манифест, правила (`AGENTS.md`) и гайды. Сборку связывает `Makefile`, JS-пакеты — pnpm-воркспейс.

| Проект           | Папка              | Что это                                                         |
| ---------------- | ------------------ | --------------------------------------------------------------- |
| Демон `metaboxd` | `apps/metaboxd/`   | Go, модуль `metabox`. Владеет конфигом и раздаёт встроенную SPA |
| Фронтенд         | `apps/web/`        | Vite + React, пакет pnpm-воркспейса. Собирается внутрь демона   |
| Генератор схемы  | `tools/schemagen/` | Go, отдельный модуль. Строит Zod-схему из форка sing-box        |

Стенд и целевое окружение OpenWrt — `.devcontainer/`, CI — `.github/workflows/`.

## Как работать

Нужны Go из [`.go-version`](./.go-version), Node и pnpm из полей `engines` и `packageManager` в [`package.json`](./package.json). Первым делом `pnpm install` — он же ставит git-хуки.

Go-команды выполняются из каталога модуля: модуля в корне нет. Сборка, генерация и линт идут через `make` из корня, тесты демона допустимо гонять и напрямую — `cd apps/metaboxd && go test ./...` ([`CONTRIBUTING.md`](./CONTRIBUTING.md)).

| Команда                 | Что делает                                                                                                                    |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `make daemon`           | собирает SPA и демон в `dist/metaboxd`                                                                                        |
| `make dev`              | dev-сервер фронта                                                                                                             |
| `make dev-mock`         | dev-сервер на моках MSW: демон и sing-box не нужны, данные берутся из фикстур слайсов                                         |
| `make dev-mock-missing` | то же, но моки отвечают только там, где ручек у демона ещё нет; остальное идёт на живой демон                                 |
| `make schema`           | перегенерирует схему из форка                                                                                                 |
| `make schema-daemon`    | перепечатывает контракт демона для панели — `apps/web/src/shared/api/daemon.generated.ts`                                     |
| `make test`             | тесты Go и фронта                                                                                                             |
| `make lint`             | строгий линт Go по обоим модулям                                                                                              |
| `make up`               | поднимает стенд так, как работает роутер: демон из пакета отдаёт встроенную SPA, рядом целевое окружение с sing-box           |
| `make up-dev`           | то же плюс дев-сервер Vite с HMR на 5173                                                                                      |
| `make daemon-target`    | собирает демон под целевое окружение внутри dev-контейнера; `make daemon` на macOS даёт darwin-бинарь, непригодный для target |
| `make stand-reset`      | возвращает конфиг стенда к эталону из образа                                                                                  |
| `make apply-check`      | цикл Apply на целевом окружении                                                                                               |
| `make reach-check`      | проверяет, что панель отвечает из локальных сетей стенда и не отвечает из внешней                                             |
| `make package`          | собирает пакет панели для устройства — той же стадией, что ставит её в стенд                                                  |
| `make stand-base`       | собирает базу стенда из образа устройства с downloads.openwrt.org                                                             |
| `make hooks`            | ставит git-хуки lefthook; `pnpm install` делает это сам                                                                       |

Формат и линт — `pnpm format`, `pnpm lint`; обе команды идут по всему репозиторию из корня. Перед правкой кода читается `AGENTS.md` того проекта, в котором работаешь.
