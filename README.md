# metabox

Веб-панель для sing-box на OpenWrt: графическое редактирование конфига, каталог rule-set и рантайм-дашборд. Поставляется одним Go-демоном со встроенной SPA.

Требования и решения — [`docs/PRD.md`](./docs/PRD.md).

## Состояние

Каркас. Продуктового кода нет. Из 32 критериев приёмки прогоном подтверждён один (AC-21), два опровергнуты (AC-17, AC-20), два написаны и ни разу не запускались (AC-18, AC-22), остальные 27 не начаты.

| Часть                                                                  | Состояние         | Что есть                                                                                                                                                                    |
| ---------------------------------------------------------------------- | ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Демон (`cmd/metaboxd`)                                                 | каркас            | HTTP-сервер с единственным `GET /healthz`. Ни REST API, ни встроенной статики                                                                                               |
| Генератор схемы (`tools/schemagen`)                                    | работает          | `make schema` собирает Zod-схему из форка `v1.13.18-extended-2.6.5`: 95 типов из шести реестров, union'ы правил, таблица переопределений                                    |
| Фронт (`web/`)                                                         | каркас + схема    | Vite, React 19, слои FSD, примитивы shadcn, Zod со сгенерированной схемой. TanStack, Zustand, React Hook Form не подключены                                                 |
| Стенд (`.devcontainer/`)                                               | работает частично | dev + target на OpenWrt 24.10.8 с sing-box-extended. `make apply-check` проходит цикл Apply целиком. `make up` не поднимает ни фронт с HMR, ни демон — AC-20 не выполняется |
| Config Editor, Rule-set Manager, Runtime Dashboard, Device Integration | не начаты         | —                                                                                                                                                                           |
| Тулинг                                                                 | настроен          | pnpm-воркспейс, oxlint и oxfmt каскадом от корня, type-aware линт, lefthook, commitlint, CI                                                                                 |

## Безопасность

Аутентификации в v1 нет — осознанное решение, риск R-1 в PRD. Демон слушает только LAN-интерфейс и не должен быть доступен из интернета: устройство, дотянувшееся до панели, управляет маршрутизацией всей сети. Аутентификация — первый пункт roadmap после v1.

## Сборка

Нужны Go, Node из [`.nvmrc`](./.nvmrc) и pnpm из поля `packageManager` в [`package.json`](./package.json).

| Команда            | Что делает                             |
| ------------------ | -------------------------------------- |
| `make daemon`      | собирает SPA и демон в `dist/metaboxd` |
| `make dev`         | dev-сервер фронта                      |
| `make schema`      | перегенерирует схему из форка          |
| `make test`        | тесты Go и фронта                      |
| `make up`          | поднимает devcontainer-стенд           |
| `make apply-check` | цикл Apply на целевом окружении        |
